# 금산군 상징물에 관한 조례

## 제1조(목적)

제1조(목적) 금산군(이하 "군"이라 한다)의 군 상징물을 정함으로써 충절과 청정 고장으로써의 이미지를 제고하고 군민들의 희망과 자긍심을 고취시키며 애향심을 복돋우고자 함을 목적으로 한다.

## 제2조(군 상징물)

제2조(군 상징물) 군 상징물은 다음 각호와 같다. 
  1. 새 : 파랑새(희망과 행복을 상징) 
2. 나무 : 소나무(충절과 절의를 상징) 
3. 꽃 : 모란(인삼약초 고장임을 상징) 
4. 물고기 : 감돌고기(청정 금산을 상징)
